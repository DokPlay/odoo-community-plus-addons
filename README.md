# Odoo Community Plus Addons

Free add-ons for Odoo Community Edition.

| Module | Supported version | Status | Description |
| --- | --- | --- | --- |
| [CP Module Health Checker](https://github.com/DokPlay/odoo-community-plus-addons/blob/19/cp_module_health_checker/README.md#cp-module-health-checker) | Odoo 19.0 Community only | Free | Checks installed Odoo modules for metadata and dependency issues. |

## Repository layout

Each add-on lives in its own folder at the repository root.

```text
odoo-community-plus-addons/
  cp_module_health_checker/
```

Do not copy the Odoo source tree into this repository.
