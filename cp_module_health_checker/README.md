# CP Module Health Checker

Free module health audit for Odoo 19 Community Edition.

This is not an official Odoo module. It is a free addon for Odoo Community Edition.

## Features

- Shows installed Odoo modules
- Detects missing author, license, version, website and description
- Detects dependency issues
- Marks potential custom modules
- Provides OK, Info, Warning and Critical severity levels

## Supported version

Odoo 19.0 Community only.

## Installation

Copy the `cp_module_health_checker` folder to your custom addons path, update the apps list and install CP Module Health Checker.

## Usage

1. Open Module Health -> Checks -> Health Scans.
2. Create a new health scan.
3. Click Run Scan.
4. Review the totals and the Modules tab.
5. Use Open Problems or Open Critical to focus on problem modules.
